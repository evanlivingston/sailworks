Sailworks is an open-source sailing routing and navigation application. It helps sailors
plan a route through forecast weather, bring boat instruments onto the chart, and review
recorded sailing against predicted boat performance.

It is a planning and analysis aid, not a primary navigation system. Check routes against
official charts, and keep an eye on the conditions on the water.

Start with the quickstart for a first session, then follow the task pages as you need
them. The manual runs in roughly the order you will use the app: charts and weather,
routing, polars and performance, instruments and logs, race day, and workspace layout.
